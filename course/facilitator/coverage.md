# Coverage and dependency map

`../landscape.json` is the machine-readable map used by the workbench. Its connections are opportunities, not a fixed sequence. Gates remain educational recommendations. Technical prerequisites remain real.

| Capability | Suggested useful dependency | Persistent evidence | Instrument status |
|---|---|---|---|
| Trace information across a request boundary | save/export a note | source revision + request + observed intervention | runnable local bridge |
| Explain text size through actual tokens | chosen tokenizer available | byte/token comparison; vocabulary boundary | reference route; probe to build |
| Inspect a distribution and its loss | conditional probability help on demand | small generator; counterexample; entropy/loss readings | to build with learner |
| Trace an attention computation | matrix shapes; softmax | Q/K/V values, mask intervention, alternative explanation | to build with learner |
| Trace a parameter update | prediction/loss; derivatives in context | finite-difference check, loss curve, holdout | to build with learner |
| Distinguish training, tuning and prompting | loss and request boundary | controlled comparison, explicitly bounded interpretation | reference/comparison route |
| Measure an inference tradeoff | stable request/config | timings, generation limits, quality failures, resource scope | per-run time/counts available; benchmark to build |
| Locate a retrieval failure | context boundary; document revisions | known/changed/absent/conflicting probes | native route unverified |
| Verify a tool actually ran | schema and dispatch access | receipt and failure/stop trace | model tool dispatch deliberately not enabled |
| Diagnose lost discipline/continuity | exact context assembly | version hashes, state, regression record | bridge structural checks; model behaviour partly unverified |
| Trace a codex claim to raw evidence | stable revisions | edition manifest, contradiction, original payload | runnable deterministic source edition |

All theory is available on request. Primary references are linked in the landscape. They are instruments, not mandatory chapters or proof of skill. Toy computations must be labelled; their limits cannot be extrapolated into claims about frontier-model internals.
